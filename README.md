# Misión 112 — Academia Escolar de Emergencias

Plataforma educativa modular y gamificada de emergencias y autoprotección para niños de 7 a 12 años (Protección Civil y 112).

## Características principales
- **17 Catástrofes y riesgos modelados:** Inundaciones, incendios, terremotos, volcanes, tormentas, ola de calor, nevadas, vientos, maremotos, accidentes químicos, apagón, aludes, nuclear, alerta sanitaria, costeros, incendios forestales y mercancías peligrosas.
- **4 Juegos interactivos reutilizables por misión:**
  1. 🎒 Mochila de Emergencia (kit 72h)
  2. ⏱️ Línea de Tiempo (Antes / Durante / Después)
  3. ⚠️ Radar de Peligros (Decisiones seguras vs erróneas)
  4. 📞 Simulador 112 (Llamada guiada con feedback inmediato)
- **2 Niveles de edad:** Junior (7-9 años) y Senior (10-12 años).
- **🎓 Diploma personalizable** al completar los 4 retos.
- **👩‍🏫 Zona Docente / Sorteo:** Selector directo de catástrofe, generador de enlaces bloqueados y ruleta aleatoria para el aula.
